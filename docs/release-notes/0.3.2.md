A small fix for the update notice.

## Download

Download **ScreenPlayground-0.3.2.dmg** below and drag it into Applications. If you have 0.3.0 or 0.3.1, the app offers this update by itself.

## Fixed

- **The "update ready" notice is no longer upside down.** On macOS 26, its description and buttons were drawn mirrored. If you saw that while updating to this version, use Settings › Updates › **Restart to Update** (or the menu bar icon) instead; from now on the notice shows correctly.
