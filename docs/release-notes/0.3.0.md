**Screen Playground 0.3.0 lets AI agents make your demo videos.**

## Download

Download **ScreenPlayground-0.3.0.dmg** below, open it, and drag Screen Playground into Applications (replace the old copy).
- Requires macOS 15 or later.
- Runs on Apple silicon and Intel Macs.

## What's new

- **Prompt a demo video.** Ask Claude Code, the Claude app or Codex for something like *"make a 20-second demo of the signup flow"*.
  - The agent writes a short script.
  - Screen Playground clicks and types through it with a smooth, real cursor while recording.
  - It then auto-zooms on clicks, adds captions, cuts dead time and exports an MP4.
- **One-click setup.** Go to Settings › *Agents & command line* and click **Set Up…** next to Claude Code, the Claude app or Codex.
- **`pgctl`, the command-line tool, ships inside the app.** It can record, run demo scripts, add captions and zooms, cut, render review frames and export. Every command has `--json` output, and `pgctl mcp` serves the same tools to apps without a terminal.
- **Captions.** Add captions on the new timeline lane, or let agents add them. Keyboard shortcut overlays move up so they never collide.

- **Choose where everything is saved.** On first launch, a welcome screen shows where recordings will go (`~/ScreenPlayground` by default) and lets you pick another folder; it warns you if the folder syncs to iCloud Drive or Dropbox. Change it any time in Settings › Storage, which moves your projects along. If you're upgrading, your recordings stay in `~/Movies/Screen Playground`.
- **Less clutter.** Videos copied to the clipboard are cleaned up after a day.

## Safety

- **You stay in control.** While an agent runs a demo, press **Esc** or move the mouse to stop it; whatever was recorded is kept.
- **No passwords.** It never types into password fields.
- **No blind clicks.** Before each click it checks that nothing (an autofill or password-manager popup, a notification) is covering the target. If something is, it stops instead of clicking.

## Fixed

- Recording a screen area where nothing moves no longer fails with "No video was captured".
