A quick fix for projects from earlier versions, plus a much easier way to crop.

## Download

Download **ScreenPlayground-0.3.1.dmg** below and drag it into Applications. If you already have 0.3.0, it will offer this update by itself.

## Fixed

- **Projects made with earlier versions open again.** 0.3.0 showed "Couldn't open project — the data couldn't be read because it is missing" for recordings made with 0.2 or earlier. Your files were never damaged; they open normally now.
- **The editor window keeps its size.** It no longer shrinks itself to fit what's on screen.

## New

- **Crop by dragging.** Click **Crop** to see the whole recording with a glowing frame.
  - Drag the corners or edges to resize; drag inside to move.
  - Pick Free, 16:9, 4:3, 1:1 or 9:16.
  - Press Return to apply or Esc to cancel.
